# ReLife Data Studio

Éditeur graphique local du schéma de données ReLife.

## Démarrage

```powershell
npm.cmd install
npm.cmd run dev
```

Ouvrez ensuite l’adresse indiquée dans le terminal. Les changements sont sauvegardés automatiquement dans le navigateur. Le schéma peut être importé/exporté en JSON et exporté en SQL.
